# Flujo Avatar

Black and white eyes in a world that evolves from real Flujo state. Flujo remains the backend, execution engine and embedded control surface. Our OpenRouter conversation service handles voice before setup; the user connects their own subscription, API or local model for thinking and work.

This repository owns the portable avatar presentation and native audio adapter. The initial Flujo integration is on [codex/avatar-world](https://github.com/mario-andreschak/FLUJO/tree/codex/avatar-world), with an in-progress `/world` route. Voice integration and broader capability journeys are still being built.
